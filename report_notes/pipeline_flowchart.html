Mean state of each cluster

X̄w = meanw X,   X̄i = meani X,   X ∈ {V, W, L, Ts, Ti}

The "standard atmosphere" of the day: the RTM corrects every pixel towards this state. Also used as base state for B1 (with σ).

correct_day.m (Mw, Mi)
A6bRTM correction
Iteration k = 1, 2 (NIT = 2, as in the paper) · every valid ocean pixel

1Ice fraction used

c = siconc  (k = 1)
c = cnew  (k = 2)

→

2Reference state

Xref = (1 − c)·X̄w + c·X̄i

mixes the two tie-point means with c (also Lref)

→

3RTM correction

ΔTB = RTM(Xref, Lref, c, θ) − RTM(V, W, Lref, Ts, Ti, c, θ) Eq. 14

L is not corrected: Lref in both runs

6New ice fraction

cnew = clip(SICc, 0, 1);
< 0.15 → 0

←

5Corrected SIC

SICc = (TB,c − Tcp,water) / (Tcp,ice − Tcp,water) Eq. 16

←

4Corrected TB and tie points

TB,c = TB + ΔTB Eq. 13

Tcp,water = meanw TB,c,  Tcp,ice = meani TB,c

loop: cnew goes back to ① · iteration 3 changes SIC by < 0.4 % → stop after k = 2

The water tie point barely moves: the correction pulls every pixel towards the cluster mean, so the mean of Mw stays the same and only the spread shrinks.

Traps to explain in the report

Mean SIC over water = 0 by construction. Tp,water is the mean of the same pixels, so only the std is a result.
L in both runs. Per-pixel L makes the std worse (A6: 11.5 % N vs. 10.6 % raw), because ERA5 clouds do not match the 1973 clouds pixel by pixel.
c is needed by the RTM but is the output. Hence the iteration: start with ERA5 siconc, then use our own SIC.
Southern ice tie point is weak (siconc > 0.8: 200 K, std 26 K): small contrast → large SIC std.
