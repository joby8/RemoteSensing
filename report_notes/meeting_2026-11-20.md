## Note on point 4

In iteration 1 c is ERA5 siconc, which is already 0..1, so the clip there changes nothing. The change that matters
is that low SIC values (0–15 %) are no longer forced to 0 before iteration 2: thin/edge ice now gets its mixed
ice/water reference. This is a deviation from the paper's step (truncate + open-water filter) and goes into the report.
